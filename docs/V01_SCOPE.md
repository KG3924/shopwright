# v0.1 scope

Shipped in this cut:

- Photo upload → interpretation → studio
- Product URL fetch + interpretation
- Six studio pieces with photographs
- Three-ish construction routes per piece
- Parametric W/D/H with live cut list and orthographic views
- Five ranks with gated technique modules
- Eight species with stain / weather / movement / weight
- Lumber sourcing biased to Allen / DFW, national big-box fallback
- Fastener buy lists per route
- Master Woodworker chat against the current packet
- Explicit confidence and uncertainty list

Deliberately not in 0.1:

- True 3D exploded views or CAD export
- CNC G-code / nesting that rivals CutList Plus
- Perfect clones of a commercial SKU
- Accounts, cloud save, sharing a packet as a link
- Video technique lessons
- Live inventory / prices from Home Depot
- Arbitrary ZIP → every hardwood dealer in America

Next cuts that would matter:

1. User-editable part graph (tap a length, correct it, lock it)
2. Sheet-goods nesting
3. A printable one-sheet PDF
4. More templates (bed, desk, workbench, outdoor table)
5. Shop inventory (“I don’t have a table saw”) rewriting the route automatically
